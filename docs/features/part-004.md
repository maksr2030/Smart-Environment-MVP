# سجل الميزات العام، الجزء 4

هذا الجزء يعرض الوصف العام للميزات دون الأكواد أو التفاصيل التنفيذية أو المصادر الداخلية.

### 151. منصة تقييم الأثر البيئي لمشاريع الطاقة النووية

- المعرف: `GEN-093`
- المجال: الزراعة والتربة؛ الطاقة والاستدامة؛ الحوكمة والبحث والخدمات
- نوع الوظيفة: خدمة أو وظيفة بيئية وصفية
- الوصف العام: قدرة مؤسسية بعنوان «منصة تقييم الأثر البيئي لمشاريع الطاقة النووية» تركز على خدمة أو وظيفة بيئية وصفية ضمن مجال الزراعة والتربة، الطاقة والاستدامة. تساعد على تنظيم المؤشرات ذات الصلة، وتحويلها إلى مخرجات تحليلية وتقارير وتوصيات قابلة للمراجعة ودعم القرار.
- القيمة الوظيفية: تضيف قيمة عملية إلى خدمة أو وظيفة بيئية وصفية من خلال تحسين وضوح البيانات، اتساق المتابعة، وسرعة الاستجابة المؤسسية.
- تصنيفات القدرة: التحليل، التقييم، المقارنة
