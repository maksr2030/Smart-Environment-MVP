# سجل الميزات العام، الجزء 7

هذا الجزء يعرض الوصف العام للميزات دون الأكواد أو التفاصيل التنفيذية أو المصادر الداخلية.

### 301. منصة إدارة الكوارث البيئية في المناطق الساحلية

- المعرف: `GEN-168`
- المجال: الكوارث والأزمات؛ الزراعة والتربة
- نوع الوظيفة: خدمة أو وظيفة بيئية وصفية
- الوصف العام: قدرة مؤسسية بعنوان «منصة إدارة الكوارث البيئية في المناطق الساحلية» تركز على خدمة أو وظيفة بيئية وصفية ضمن مجال الكوارث والأزمات، الزراعة والتربة. تساعد على تنظيم المؤشرات ذات الصلة، وتحويلها إلى مخرجات تحليلية وتقارير وتوصيات قابلة للمراجعة ودعم القرار.
- القيمة الوظيفية: تضيف قيمة عملية إلى خدمة أو وظيفة بيئية وصفية من خلال تحسين وضوح البيانات، اتساق المتابعة، وسرعة الاستجابة المؤسسية.
- تصنيفات القدرة: الإدارة، التنسيق، المتابعة
